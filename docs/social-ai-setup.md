# المساعد الذكي على واتساب وإنستجرام وماسنجر وتيك توك

## الفكرة في سطرين

المخ موجود أصلاً — `utils/supportBrain.js` هو نفسه اللي بيرد على الموقع، بنفس
الأدوات وبنفس الكتالوج. اللي اتضاف هنا هو **طبقة القنوات** بس: باب يستقبل
الرسالة من المنصة، وبوسطجي يودّي الرد. مفيش مخ تاني، ومفيش كتالوج تاني.

```
واتساب ─┐
إنستجرام ─┤→  /api/social/webhook/meta  ─→ socialInbox ─→ supportBrain (Claude)
ماسنجر  ─┘                                     │              │
تيك توك ───→ /api/social/webhook/tiktok ───────┘              ├─ searchProducts (13,000 منتج)
                                                              ├─ shippingFacts
                                                              ├─ capture_order  → SocialLead
                                                              └─ request_human  → تنبيه للفريق
```

## الملفات

| الملف | بيعمل إيه |
|---|---|
| `routes/socialWebhook.route.js` | المسارات. مركّبة في `app.js` **فوق** الـ rate limiter والـ coming-soon gate |
| `controllers/socialWebhook.controller.js` | التحقق من التوقيع، قراءة شكل كل منصة، الرد بـ 200 فورًا |
| `utils/socialChannels.js` | الإرسال لكل منصة، تقطيع الرسايل الطويلة، التحقق من التوقيع |
| `utils/socialInbox.js` | المسار الكامل: thread → Claude → رد → حفظ |
| `models/socialThread.model.js` | محادثة واحدة مع شخص واحد على قناة واحدة |
| `models/socialLead.model.js` | طلب اتاخد في الشات، قبل ما يبقى أوردر |
| `scripts/socialSmokeTest.mjs` | اختبار كامل للمسار من غير ما يلمس سيرفر حد |

وتعديلين صغيرين على كود موجود:

* `utils/supportBrain.js` — بقى بياخد `extraTools` و `systemExtra` اختياريين.
  من غيرهم بيشتغل بالظبط زي الأول (فيه اختبار بيتأكد من ده).
* `utils/supportTools.js` — `searchProducts` بقى بيرجّع `url` جاهز للمنتج.
  الموديل كان بيخترع اللينك من الـ slug والصفحة بالـ id، فكان بيطلع 404.

## التشغيل

### ١. المتغيرات

انسخ `backend/env.social.example` وكمّل الخانات. الأهم:

* `ANTHROPIC_API_KEY` — من غيره الشات بيشتغل بمحرك القواعد بس.
* `META_APP_SECRET` + `META_VERIFY_TOKEN` — من غيرهم كل webhook بيترفض.

### ٢. تطبيق Meta واحد لثلاث قنوات

`developers.facebook.com` → Create App → **Business**، وبعدين ضيف المنتجات
الثلاثة: WhatsApp، Instagram، Messenger.

الـ Webhook واحد لهم كلهم:

```
Callback URL:  https://<api-domain>/api/social/webhook/meta
Verify Token:  نفس اللي في META_VERIFY_TOKEN
```

الحقول المطلوب الاشتراك فيها: `messages` (واتساب)، `messages` +
`messaging_postbacks` (إنستجرام وماسنجر).

> التوكن المؤقت في صفحة API Setup بيموت بعد ٢٤ ساعة. اعمل **System User**
> من Business Settings وخد منه توكن دائم، وإلا الشات هيقف بكرة.

### ٣. تيك توك

تيك توك **مش** ناشرة API عام للرسايل الخاصة. الطريق الرسمي الوحيد هو
Messaging Partner معتمد (Respond.io، SleekFlow، Gupshup، Infobip، Pancake،
Qiscus، Blip، وغيرهم) بيمسك الإنبوكس ويوصّلنا الرسالة.

عشان كده القناة دي متعاملة كـ relay: الشريك بيبعت لـ
`/api/social/webhook/tiktok` بالشكل ده، موقّع بـ HMAC-SHA256 في هيدر
`x-relay-signature`:

```json
{ "userId": "...", "messageId": "...", "text": "...", "displayName": "..." }
```

والرد بيرجع للشريك على `TIKTOK_RELAY_URL`. كده لو الشريك اتغيّر، أو لو تيك توك
فتحت الـ API بكرة، الملف الوحيد اللي هيتغيّر هو الكنترولر.

### ٤. الاختبار

```bash
cd backend
npm run test:social
```

بيشغّل التطبيق الحقيقي على HTTP حقيقي، وبيزوّر بس الشبكة الخارجة (Claude و
Meta) والتخزين. ولو عايزه يلمس داتابيز حقيقية ويجرّب البحث في الكتالوج نفسه:

```bash
MONGO_URI=mongodb://localhost:27017/blgomla-test npm run test:social
```

بعد النشر، اطمن على الحالة:

```bash
curl https://<api-domain>/api/social/status
```

## قرارات مقصودة

**الـ 200 بيرجع قبل ما نفكّر.** Meta بتعيد إرسال أي webhook مردّتش عليه بسرعة،
ونداء الموديل مع دورتين أدوات مش داخل الميزانية دي. فالرد بيطلع الأول والشغل
بيكمل بعده — وعلى Vercel ده معناه إننا بنقول للمنصة تستنى (`runAfterResponse`).

**التوقيع بيتشيك قبل أي حاجة.** اللينك ده عام بحكم وظيفته، وPOST مش موقّع لو
وصل للمعالجة معناه إن أي حد يقدر يخلّي المساعد يقول اللي هو عايزه، على رقمنا،
لعملائنا، وعلى حسابنا.

**الأوردر بينزل `SocialLead` مش `Order`.** الأوردر الحقيقي وراه عميل مسجّل
وعنوان محفوظ وسلة مسعّرة ودفع. اللي بيطلع من شات ده نية بعنوان نص مكتوب —
فبتتسجّل هنا وبني آدم يحوّلها.

**المساعد مش بيقدر يشوف أوردرات حد على السوشيال.** مفيش تسجيل دخول هنا، ورقم
تليفون بيطابق صف في الداتابيز ده مصادفة مش إثبات. بيطلب رقم الأوردر ويحوّل لموظف.

**لما بني آدم ياخد المحادثة، البوت بيسكت** — والسكوت مش بيتفك بمؤقّت. عميل
مستني رد ده مشكلة تبان في إنبوكس الفريق، مش حاجة نغطّيها بإن البوت يرجع يتكلم
في نص التسليم.

## اللي لسه ناقص

* **شاشة إنبوكس في لوحة التحكم** — الداتا كلها متسجّلة (`SocialThread`،
  `SocialLead`) بس مفيش صفحة بتعرضها. التنبيهات دلوقتي بتروح واتساب + جرس
  الإشعارات.
* **الرد على كومنتات إنستجرام وفيسبوك** — ده حقل webhook تاني (`comments`)
  ونفس المخ ينفع يرد عليه.
* **ربط حساب العميل** — كود تحقق قصير يتبعت في الشات يخلّي أدوات الأوردرات
  تشتغل على السوشيال زي ما بتشتغل على الموقع.
